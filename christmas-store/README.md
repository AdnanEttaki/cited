# Evergleam — Christmas Shopify Brand Kit & Store Template (images)

Final images are in `images/` (2x resolution, 2880px wide):

| File | What it is |
|---|---|
| `images/brand-kit.png` | Brand core, logo suite, palette + usage ratio, typography, UI kit, art direction, 10 buying-psychology triggers, voice |
| `images/homepage.png` | Desktop homepage template |
| `images/product.png` | Desktop high-converting product page (PDP) |
| `images/mobile.png` | Mobile PDP with sticky ATC, cart drawer, mobile homepage |

Sources are plain HTML in `src/`. Edit text/colors there and re-render with:

```
node render.js brand-kit:1440 homepage:1440 product:1440 mobile:1440
```
